# 영어 타자연습 — 발음과 뜻을 함께

영어 발음을 모르는 사람이 **타자를 치면서 그 단어의 한글 발음과 뜻을 함께 익히는** 웹사이트입니다.

설치·인터넷·회원가입이 필요 없습니다. `index.html` 을 더블클릭하면 바로 실행됩니다.

---

## 실행

| 무엇 | 어떻게 |
|---|---|
| **앱 실행** | `index.html` 더블클릭 |
| 콘텐츠 검증 | `tools/validate.html` 더블클릭 |
| 로직 테스트 | `tools/test.html` 더블클릭 |
| 전체 검증 (Node 필요) | `node tools/verify-all.js` |

Node.js 는 **선택 사항**입니다. 없어도 모든 검증을 브라우저에서 할 수 있습니다.

---

## 단축키

| 키 | 기능 |
|---|---|
| `Enter` | 다음 문항 |
| `Esc` | 다시하기 |
| `F2` | 발음 켜기/끄기 |
| `F4` | 뜻 켜기/끄기 |
| `F9` | 발음 기호 범례 |

**발음과 뜻은 기본적으로 꺼져 있습니다.** 스스로 먼저 읽어 보게 하려는 의도이며, 두 토글은 서로 독립이라 원하는 조합으로 쓸 수 있습니다.

---

## 화면 구성

```
        f  æ           ← 발음 구분 표시 (한글로는 구분 안 되는 소리)
       [팬]            ← 한글 발음 (굵은 글자 = 강세)
        ᵗ              ← 철자 정보 (예: 철자는 t 인데 ㄹ 로 약해짐)
      ─────────
       f  a  n         ← 타이핑 대상
      ─────────
       선풍기           ← 뜻
```

한글로는 `fan` 과 `pan` 이 **똑같이 "팬"** 입니다. `light`/`right`, `think`/`sink` 도 마찬가지입니다.
위층의 작은 기호가 그 차이를 알려줍니다. `F9` 를 누르면 각 기호의 발음 방법을 볼 수 있습니다.

## 콘텐츠를 고치거나 늘리려면

**`js/` 는 건드리지 않습니다.** 데이터 파일만 고치면 됩니다.

```javascript
// data/words.js
w('w0003','fan','팬',[m(0,'f'),m(0,'ae')],'선풍기','beginner','daily');
//  id      영어   발음   구분 표시              뜻       난이도      주제
```

고친 뒤에는 반드시 검증합니다.

```
tools/validate.html 을 열어 "위반 없음" 확인
```

> **발음 표기가 마음에 안 들면 `docs/pronunciation-rules.md` 를 먼저 고치세요.**
> 개별 항목만 고치면 다음에 추가하는 항목에서 또 어긋납니다. 규칙표가 원본입니다.

---

## 알아두실 점

**한글 표기는 발음의 근사치입니다.** 한글에는 `f`, `v`, `th`, `r`/`l` 을 구분할 글자가 없어서, 표기만으로는 담기지 않는 소리가 있습니다. 위층의 구분 표시가 그 간극을 메우려는 장치이지만, 간극을 없애지는 못합니다.

또한 이 프로젝트에는 발음을 검수한 원어민이나 전문가가 없습니다. 검증 스크립트가 확인하는 것은 **"규칙과의 일관성"** 이지 **"발음이 실제로 맞는가"** 가 아닙니다. 이상한 표기를 발견하시면 위 방법으로 고쳐 주세요.

---

## 만든 방식

**발음 데이터는 런타임에 생성하지 않습니다.** LLM API를 부르는 곳이 한 곳도 없습니다.

대신 이렇게 만들었습니다.

```
1. 발음 표기 규칙을 먼저 문서로 확정   →  docs/pronunciation-rules.md
2. 그 규칙에 따라 1,323개 항목을 생성   →  data/
3. 규칙을 지켰는지 기계적으로 검증      →  tools/validate.html
```

규칙표가 원본이고 데이터는 그 결과물입니다. 표기를 바꾸고 싶으면 규칙을 고치고 다시 만들면 됩니다.

검증 스크립트는 **자기 자신도 테스트합니다.** 각 규칙마다 일부러 틀린 데이터를 넣고 실제로 잡히는지
확인합니다 (`tools/validator-self-test.js`). 검증기에 버그가 있어서 전부 통과시키면
"위반 0건"이라는 거짓 안심을 얻게 되기 때문입니다.

### 코드 구조

```
서비스   Bootstrap · PracticeSession · Settings        순서를 안다
도메인   ContentStore · TypingEngine · StatsTracker     자기 일만 안다
상태     AppState (보관 + 구독 통지)
뷰       Layout · Text · Annotation · Result · Control · Legend
입력     InputHandler
```

빌드 도구도 프레임워크도 쓰지 않습니다. `file://` 로 열어야 하므로
ES Module 대신 IIFE 패턴을 씁니다.

### 검증

```
node tools/verify-all.js     정적 규약 8 + 콘텐츠 7 + 로직 1 = 16항목
```

Node 가 없으면 `tools/validate.html` 과 `tools/test.html` 을 브라우저로 열면 됩니다.
