# 영어 발음 한글 표기 규칙표

**버전** 1.0 · **기준** 미국식 영어(General American) · **최종 수정** 2026-08-16

이 문서는 이 프로젝트의 모든 발음 데이터가 따라야 하는 **표기 규칙**이다. 데이터를 고치거나 추가할 때는 반드시 이 규칙을 따른다.

---

## 이 규칙표가 존재하는 이유

한글로 영어 발음을 적는 데에는 **정답이 없다.** `water` 를 "워터"로도 "워러"로도 적을 수 있고 둘 다 근거가 있다.

그래서 이 문서가 하는 일은 **"우리는 이렇게 적는다"를 고정하는 것**이다. 정확성보다 **일관성**이 목표다. 1,300개 항목이 서로 다른 기준으로 적혀 있으면 학습자가 규칙을 발견할 수 없다.

표기가 마음에 들지 않으면 **이 문서를 고치고 데이터를 재생성**한다. 데이터를 직접 고치면 다음 항목에서 또 어긋난다.

---

## 규칙 적용 우선순위

규칙이 충돌하면 위쪽을 먼저 적용한다.

| 순위 | 규칙 | 이유 |
|---|---|---|
| 1 | 예외 목록 | 규칙으로 설명 안 되는 단어를 먼저 걸러낸다 |
| 2 | 연음·축약 (문장만) | 단어 경계를 넘으므로 단어 규칙보다 먼저 |
| 3 | flap T | 자음 매핑을 덮어쓴다 |
| 4 | 어말 자음 처리 | 음절 구성을 결정한다 |
| 5 | 자음·모음 매핑 | 기본 |
| 6 | 강세 | 표기 확정 후 위치만 지정 |
| 7 | 표시 부착 | 글자 인덱스가 정해진 뒤 |

### r 과 l 은 두 겹으로 구분한다

한글에는 `ㄹ` 하나뿐이므로 **표기와 표시를 함께** 쓴다.

| | 표기로 구분 | 표시로 구분 |
|---|---|---|
| light | **라**이트 (평순) | `l` |
| right | **롸**이트 (원순) | `r` |
| low | **로**우 | `l` |
| row | **뤄**우 | `r` |

원순화 대응: `ra`→롸 `re`→뤠 `ri`→뤼 `ro`→뤄 `ru`→루

**표시가 꺼져 있어도 표기만으로 구분된다.** 이것이 1차 방어선이다.

### 자음군

한글 초성에 못 붙는 자음 연쇄는 `으` 를 넣어 나눈다. `s` + 자음은 `스` 로 시작.

| 예 | 표기 |
|---|---|
| strike | 스트롸이크 |
| spring | 스프링 |
| class | 클래스 |
| place | 플레이스 |

### r-색채 모음

모음 뒤 `r` 은 **글자를 더 만들지 않고** 앞 모음 글자에 `r` 표시만 붙인다.

| IPA | 예 | 한글 | 표시 위치 |
|---|---|---|---|
| ɜːr | bird | 버드 | `r` @0 |
| ɑːr | car | 카 | `r` @0 |
| ɔːr | four | 포 | `f` @0, `r` @0 |
| ɪər | here | 히어 | `r` @1 |
| eər | air | 에어 | `r` @1 |

> `four` 에서 `f` 와 `r` 이 **같은 글자 `포`** 에 붙는다. 한글은 초성·중성을 한 글자에 모아 쓰므로 불가피하다. 한 글자에 표시가 최대 3개까지 걸릴 수 있다.

### `oʊ` 는 "오"가 아니라 "오우"

`go` 를 "고"로 적으면 한국어 [고]가 되어 실제 [ɡoʊ] 와 멀어진다. `boat`→보웃, `home`→호움. 단 **약음절에서는 "오"로 축약** (`photo`→포토).

## 3. 어말 자음

### 단모음 직후의 파열음 → **받침**

| 자음 | 받침 | 예 |
|---|---|---|
| p, b | ㅂ | cap → 캡, job → 잡 |
| t | ㅅ | cat → 캣, sit → 씻 |
| d | ㄷ | bad → 밷, red → 뤧 |
| k, g | ㄱ | book → 북, bag → 백, dog → 독 |

미국 영어의 어말 파열음은 대개 **파열 없이** 끝난다. 한국어 받침도 그렇다. 받침이 실제 소리에 더 가깝고 음절 수도 맞는다 (`cat` 1음절 → 캣 1음절).

`t`→ㅅ / `d`→ㄷ 로 나눈 것은 소리가 달라서가 아니다(한국어에서 둘 다 [t̚]). **철자를 되짚을 단서**를 남기기 위함이다.

### 이중모음·r-색채 모음 직후의 파열음 → **"으" 추가**

| 예 | 표기 | 이유 |
|---|---|---|
| bike | 바이크 | `aɪ` 이중모음 |
| road | 로우드 | `oʊ` 이중모음 |
| bird | 버드 | `ɜːr` r-색채 |
| card | 카드 | `ɑːr` r-색채 |

이중모음·r-색채 모음 뒤에 받침을 얹으면 읽기가 무너진다("바잌", "벋").

### 마찰음·파찰음 → 항상 "으"/"이" 추가

| 자음 | 추가 | 예 |
|---|---|---|
| s, z | 스 / 즈 | bus → 버스, nose → 노우즈 |
| f, v | 프 / 브 | leaf → 리프, love → 러브 |
| θ, ð | 쓰 / 드 | bath → 배쓰, with → 위드 |
| ʃ, ʒ | 시 / 지 | wish → 위시, beige → 베이지 |
| tʃ, dʒ | 치 / 지 | watch → 워치, edge → 에지 |

이 소리들은 한국어 받침으로 낼 수 없다. `bus` 를 "붓"으로 적으면 [put̚] 이 되어 `but` 과 구분되지 않는다.

### 비음·유음

| 자음 | 처리 | 예 |
|---|---|---|
| m | 받침 ㅁ | time → 타임 |
| n | 받침 ㄴ | man → 맨 |
| ŋ | 받침 ㅇ | sing → 싱 |
| l | 받침 ㄹ + `l` 표시 | feel → 필, school → 스쿨 |
| r | 표기 없음 + `r` 표시 | car → 카, door → 도어 |

## 4. flap T — 약화된 t/d

**모음(또는 r) + `t`/`d` + 강세 없는 모음** 환경에서 `t`/`d` 는 `ㄹ` 로 적고 `flap_t` 표시를 붙인다.

| 영어 | 표기 | 표시 |
|---|---|---|
| water | 워러 | `flap_t`@1, `r`@1 |
| better | 베러 | `flap_t`@1, `r`@1 |
| city | 씨리 | `flap_t`@1 |
| little | 리를 | `l`@0, `flap_t`@1 |
| party | 파리 | `r`@0, `flap_t`@1 |
| ready | 뤠리 | `r`@0, `flap_t`@1 |

### 적용하지 않는 경우

| 조건 | 예 | 표기 |
|---|---|---|
| 뒤 모음에 강세 | attack | 어택 |
| 어두 | table | 테이블 |
| `s` 뒤 | sister | 씨스터 |
| 자음 앞 | catch | 캐치 |

### `flap_t` 표시가 하는 일

표시가 없으면 학습자는 `water` → "워러"를 **외울 뿐 응용하지 못한다.** 표시가 있으면 범례에서 원리를 읽고 `butter`, `letter`, `matter` 에 스스로 적용한다.

## 5. 강세

주강세가 놓이는 **한글 글자**에 `stress` 표시를 붙인다.

| 영어 | 표기 | 표시 |
|---|---|---|
| banana | 버내너 | `stress`@1, `ae`@1 |
| hotel | 호텔 | `stress`@1 |
| water | 워러 | `stress`@0, `flap_t`@1, `r`@1 |
| computer | 컴퓨러 | `stress`@2, `flap_t`@3, `r`@3 |

**규칙**
- **주강세 1개만** 표시. 부강세는 표시하지 않는다
- **1음절 단어는 표시하지 않는다** (강세가 거기일 수밖에 없어 정보가 없다)
- 문장에서는 각 단어의 **어휘 강세**만. 문장 강세는 다루지 않는다 (문맥에 따라 달라져 고정 불가)

## 6. 연음·축약 (문장 전용)

**아래 18개 목록만 적용한다.** 목록 밖의 연음은 반영하지 않는다.

| # | 영어 | 표기 | 걸치는 단어 수 | 비고 |
|---|---|---|---|---|
| 1 | want to | 워너 | 2 | |
| 2 | wants to | 원츠 투 | 2 | |
| 3 | going to | 고나 | 2 | 미래 조동사일 때만 |
| 4 | got to | 가라 | 2 | `flap_t`@1 |
| 5 | have to | 해프 투 | 2 | v 가 무성화 |
| 6 | has to | 해스 투 | 2 | |
| 7 | ought to | 오라 | 2 | `flap_t`@1 |
| 8 | kind of | 카인더 | 2 | |
| 9 | sort of | 소러 | 2 | `r`@0, `flap_t`@1 |
| 10 | a lot of | 얼라러 | 3 | `l`@1, `flap_t`@2 |
| 11 | out of | 아우러 | 2 | `flap_t`@2 |
| 12 | did you | 디쥬 | 2 | |
| 13 | would you | 우쥬 | 2 | |
| 14 | could you | 쿠쥬 | 2 | |
| 15 | don't you | 돈츄 | 2 | |
| 16 | let me | 렘미 | 2 | `l`@0 |
| 17 | give me | 김미 | 2 | |
| 18 | what are | 워러 | 2 | `flap_t`@1, `r`@1 |

**문법 기능이 다르면 적용하지 않는다.** `I'm going to the store`(장소 이동)의 `going to` 는 "고나"가 아니라 "고잉 투".

### 목록 방식인 이유

모든 연음을 반영하면 `pick it up` → "피키럽"이 되는데, 타이핑 대상은 여전히 `pick it up` 이다. 학습자가 "피키럽"의 어디가 `it` 인지 찾을 수 없어 **단어-발음 정렬이 무의미해진다.**

## 7. 예외 목록

규칙으로 도출되지 않는 단어. **규칙 적용을 건너뛰고 여기 적힌 표기를 쓴다.**

| 영어 | 표기 | 사유 |
|---|---|---|
| one | 원 | 철자-발음 불일치 |
| two | 투 | `w` 묵음 |
| of | 어브 | `f` 가 [v] 로 발음 |
| colonel | 커늘 | 철자에 없는 r 소리 |
| Wednesday | 웬즈데이 | `d` 묵음 |
| February | 페브류에리 | 첫 `r` 탈락 통용 |
| comfortable | 컴퍼터블 | 음절 축약 |
| iron | 아이언 | `r` 위치 이동 |

### 예외 등재 기준

1. 철자에 있는 글자가 발음되지 않는다 (묵음)
2. 철자에 없는 소리가 발음된다
3. 같은 철자 패턴의 다른 단어와 발음이 다르다
4. 규칙대로 적으면 실제 발음과 뚜렷이 어긋난다

예외 단어는 **일관성 검사에서 제외**된다.

## 8. 표시 키 12개

| 키 | 기호 | 이름 | 부류 | 조음 방법 | 혼동 대상 |
|---|---|---|---|---|---|
| `f` | f | 에프 | 음소 | 윗니를 아랫입술에 살짝 대고 그 사이로 바람을 낸다 | ㅍ(p) |
| `v` | v | 브이 | 음소 | f 와 같은 입 모양에서 목을 울린다 | ㅂ(b) |
| `th` | θ | 무성 th | 음소 | 혀끝을 윗니와 아랫니 사이에 살짝 내밀고 바람을 낸다 | ㅆ(s) |
| `dh` | ð | 유성 th | 음소 | 무성 th 와 같은 혀 위치에서 목을 울린다 | ㄷ(d) |
| `r` | r | 알 | 음소 | 혀끝을 어디에도 대지 않고 입천장 쪽으로 말아올린다 | ㄹ(l) |
| `l` | l | 엘 | 음소 | 혀끝을 윗니 바로 뒤 잇몸에 확실히 붙인다 | ㄹ(r) |
| `z` | z | 지 | 음소 | ㅅ 자리에서 목을 울린다. 벌이 나는 소리 | ㅈ(j) |
| `zh` | ʒ | 즈 | 음소 | ʃ 자리에서 목을 울린다 | ㅈ(j) |
| `sh` | ʃ | 쉬 | 음소 | 혀를 ㅅ 보다 뒤로 물리고 입술을 살짝 내민다 | ㅅ(s) |
| `ae` | æ | 애 | 음소 | 입을 옆으로 넓게 벌리고 "애"와 "아" 중간 소리를 낸다 | ㅔ(e) |
| `stress` | ˈ | 강세 | 운율 | 이 음절을 더 길고 세게 발음한다 | — |
| `flap_t` | ᵗ | 약화된 t | 철자 정보 | 철자는 `t`/`d` 지만 미국식에서 ㄹ 에 가깝게 약해진다 | — |

**데이터의 모든 표시는 이 12개 중 하나여야 한다.** 다른 키를 쓰면 검증 스크립트가 위반으로 보고한다.

## 9. 표기 일관성 검사 패턴

같은 패턴을 가진 단어들은 **해당 부분 표기가 같아야 한다.**

### 접미사

| 패턴 | 기준 표기 | 예 |
|---|---|---|
| -tion | 션 | nation 네이션, station 스테이션 |
| -sion (자음 뒤) | 션 | mission 미션, passion 패션 |
| -sion (모음 뒤) | 전 + `zh` | vision 비전, decision 디시전 |
| -ture | 처 + `r` | nature 네이처, picture 픽처 |
| -ous | 어스 | famous 페이머스 |
| -ment | 먼트 | moment 모먼트 |
| -ness | 니스 | kindness 카인드니스 |
| -ing | 잉 | going 고잉 |
| -er / -or | 어 + `r` | teacher 티처, doctor 닥터 |
| -ly | 리 + `l` | quickly 퀴클리 |
| -able / -ible | 어블 + `l` | table 테이블, possible 파써블 |
| -age | 이지 | message 메시지 |

### -ed 는 3갈래

| 조건 | 발음 | 표기 | 예 |
|---|---|---|---|
| 무성 자음 뒤 | /t/ | 트 | walked 웍트 |
| 유성음 뒤 | /d/ | 드 | played 플레이드 |
| t/d 뒤 | /ɪd/ | 이드 | wanted 원티드 |

### 어두

| 패턴 | 요구 조건 | 예 |
|---|---|---|
| ph- | `f` 표시 필수 | phone 포운 |
| th- | `th` 또는 `dh` 표시 필수 | think 씽크, this 디스 |
| sh- | `sh` 표시 필수 | she 시 |
| wr- | `r` 표시 필수, `w` 묵음 | write 롸이트 |
| kn- | `k` 묵음 | know 노우 |
| wh- | 우/와 계열 | what 웟 |
| qu- | 쿠/퀴 | quick 퀵 |

### 검사에서 제외하는 패턴

같은 철자인데 발음이 갈리므로 일관성을 요구할 수 없다.

| 패턴 | 갈래 |
|---|---|
| -ough | though 도우 / through 쓰루 / tough 터프 / cough 코프 / bough 바우 / thought 쏫 |
| ea | bread 브렏 / break 브레익 / beach 비치 / great 그뤠잇 |
| oo | book 북 / food 푸드 / blood 블러드 / door 도어 |
| ch | chair 체어 / school 스쿨 / machine 머신 |
| -ow | now 나우 / know 노우 |

> **`-ough` 가 6갈래로 나뉜다는 사실**이 "철자에서 발음을 자동 계산한다"는 접근이 불가능한 이유다. 영어 철자는 발음을 결정하지 않는다.

## 10. 난이도 기준

### 단어

**1차 — 사용 빈도**

| 등급 | 기준 |
|---|---|
| beginner | 일상 대화·기초 교재 고빈도 (기초 1,000 단어급) |
| intermediate | 일상에서 쓰이나 기초 어휘는 아닌 중빈도 |
| advanced | 저빈도·추상적·전문적 |

**2차 — 발음 난이도 보정.** 아래 중 하나라도 해당하면 **한 단계 상향** (advanced 는 유지).

| 조건 |
|---|
| **음소 표시**가 3개 이상 (`stress`·`flap_t` 는 세지 않는다) |
| `th` 또는 `dh` 포함 |
| `zh` 포함 |
| `r` 과 `l` 이 한 단어에 함께 등장 (really, world, girl) |
| 자음군 3개 이상 연속 (strength, scripts) |
| 4음절 이상 |

### 문장

| 등급 | 단어 수 | 구성 단어 | 연음 |
|---|---|---|---|
| beginner | 4~7 | 전부 beginner | 없음 |
| intermediate | 6~10 | intermediate 이하 | 0~1개 |
| advanced | 9~14 | 제한 없음 | 제한 없음 |

단어 수와 구성 단어 조건이 어긋나면 **높은 쪽**을 따른다.

## 11. 카테고리

| 값 | 라벨 | 내용 |
|---|---|---|
| daily | 일상 | 집·생활·시간·인사 |
| food | 음식 | 식재료·요리·식당 |
| travel | 여행 | 교통·숙박·길찾기 |
| school | 학교·공부 | 수업·시험·학용품 |
| work | 직장 | 업무·회의·직업 |
| feeling | 감정·관계 | 감정·성격·가족·친구 |
| tech | 기술·IT | 기기·인터넷·프로그램 |
| nature | 자연·날씨 | 동식물·날씨·환경 |

**배정 원칙**
- 항목당 카테고리 **하나만**
- 둘 이상 해당하면 **더 좁은 쪽** (restaurant 은 daily 가 아니라 food)
- 어디에도 뚜렷이 안 속하는 기능어·일반 동사·형용사는 daily
- 어느 카테고리도 단어 60개 미만이 되지 않게 한다

## 12. 이 규칙표가 보장하지 않는 것

**발음의 절대적 정확성은 보장하지 않는다.**

이 프로젝트에는 발음을 검수할 원어민이나 전문가가 없다. 검증 스크립트가 확인하는 것은 **"규칙과의 일관성"** 이지 **"발음이 실제로 맞는가"** 가 아니다.

예를 들어 `-tion` 을 30개 단어에서 전부 "쎤"으로 잘못 적었다면, 서로 일치하므로 검증을 통과한다. 이것은 알려진 한계이며, 오류를 발견하면 **이 문서의 기준 표기를 고치고 데이터를 재생성**하는 것이 대응 방법이다.

또한 한글은 영어의 모든 소리를 담지 못한다. 표시 12개는 그 간극을 메우려는 장치이지, 간극을 없애지는 못한다. **한글 표기는 발음의 근사치이며 출발점이다.**
